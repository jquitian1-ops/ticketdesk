INICIO RÁPIDO — MODO EQUIPO (varios usuarios en red)
──────────────────────────────────────────────────────────────────

  1. Instalar dependencias:
     pip install flask flask-cors ldap3 python-dotenv

  2. Configurar entorno:
     copy .env.template .env
     (editar .env con los datos del servidor LDAP y API key)

  3. Iniciar servidor:
     python ldap_bridge.py

  4. Todos los usuarios abren en su navegador:
     http://IP-DEL-SERVIDOR:5050          (técnicos)
     http://IP-DEL-SERVIDOR:5050/portal   (usuarios finales)
