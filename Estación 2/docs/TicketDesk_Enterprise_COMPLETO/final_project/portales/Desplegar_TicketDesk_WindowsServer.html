Instalar Python 3.11
Requerido — Python 3.11 x64 con PATH
✓ Completado ▾
  1. Descarga Python 3.11 x64 desde:
    https://www.python.org/downloads/windows/
  2. Ejecuta el instalador como Administrador
  3. ⚠ Marca "Add Python to PATH" antes de instalar

✓

04
Configurar archivo .env
Clave JWT, ruta de base de datos y puerto
✓ Completado ▾

Crea el archivo C:\TicketDesk\.env con este contenido:

.env
# ─── OBLIGATORIO — cambia esta clave ─────────────
JWT_SECRET=CAMBIA_ESTA_CLAVE_LARGA_Y_SEGURA_2026

# ─── Base de datos ────────────────────────────────
DB_PATH=C:\TicketDesk\ticketdesk.db

# ─── Puerto del servidor ──────────────────────────
PORT=5050

# ─── URL pública ──────────────────────────────────
SERVER_URL=http://192.168.1.100:5050
⚠
IMPORTANTE: Cambia JWT_SECRET por una cadena larga y única. Esta clave protege todas las sesiones. Ejemplo: xK9$mP2#vL7@nQ4&wR8!tY3
05
Compartir carpeta en red
Para que los 8,000 empleados accedan a los portales
✓ Completado ▾

Con un solo comando (CMD como Administrador):

CMD — Administrador
net share TicketDesk=C:\TicketDesk\portales /grant:Everyone,READ

Los empleados acceden abriendo:

Ruta de red
\\SERVIDOR\TicketDesk\portal_usuarios.html
ℹ
También puedes distribuir el acceso directo via GPO de Active Directory para que aparezca en el escritorio de todos automáticamente.
06
Abrir puerto 5050 en el Firewall
Regla de entrada y salida en Windows Firewall
✓ Completado ▾
CMD — Administrador
netsh advfirewall firewall add rule name="TicketDesk API" protocol=TCP dir=in localport=5050 action=allow
netsh advfirewall firewall add rule name="TicketDesk API OUT" protocol=TCP dir=out localport=5050 action=allow
ℹ
Si tienes un firewall corporativo externo (Fortinet, Cisco, etc.), también deberás abrir el puerto 5050 en ese dispositivo para las PCs de empleados en otras subredes.
07
Instalar como servicio de Windows (NSSM)
Arranque automático con el servidor
✓ Completado ▾

7a. Descarga NSSM desde nssm.cc/download y copia nssm.exe a C:\TicketDesk\

7b. Instalar y configurar el servicio:

CMD — Administrador
cd C:\TicketDesk
nssm.exe install TicketDesk
En la ventana que aparece:
  Path:      C:\Python311\python.exe
  Arguments: server_enterprise.py
  Startup:   C:\TicketDesk
nssm.exe set TicketDesk AppDirectory C:\TicketDesk
nssm.exe set TicketDesk Start SERVICE_AUTO_START
nssm.exe start TicketDesk

7c. Verificar que el servidor responde:

CMD
curl http://localhost:5050/api/health
Respuesta esperada:
{"status":"ok","db":true,"version":"2.0-enterprise"}

Comandos de gestión del servicio:

Gestión
nssm.exe start TicketDesk    ← iniciar
nssm.exe stop TicketDesk     ← detener
nssm.exe restart TicketDesk  ← reiniciar
nssm.exe status TicketDesk   ← ver estado
08
Verificar acceso desde la red
Prueba desde otra PC antes de distribuir
✓ Completado ▾

Desde otra PC de la red, abre el navegador y ve a:

Navegador
http://192.168.1.100:5050/api/health
✓
Si responde {"status":"ok"} el servidor está accesible desde la red.
⚠
Si no responde: verifica el firewall de Windows (Paso 6) y que el servidor esté en la misma VLAN que los clientes.
09
Crear usuarios iniciales
Admin, técnicos y empleados de prueba
✓ Completado ▾

Primero obtén el token de administrador:

CMD
curl -X POST http://192.168.1.100:5050/api/auth/login ^
  -H "Content-Type: application/json" ^
  -d "{\"username\":\"admin\",\"password\":\"tu_password\",\"company_id\":\"me\"}"

Luego crea un técnico de TI (usa el token de la respuesta anterior):

CMD
curl -X POST http://192.168.1.100:5050/api/users ^
  -H "Authorization: Bearer TOKEN_AQUI" ^
  -H "Content-Type: application/json" ^
  -d "{\"username\":\"jgarcia\",\"display_name\":\"Juan Garcia\",\"role\":\"agent\",\"company_id\":\"me\",\"password\":\"Pass123!\"}"
ℹ
Roles disponibles: admin · agent (técnico TI) · user (empleado). Los empleados normales no necesitan cuenta — se crean automáticamente al primer login si LDAP está configurado.
