Create PostgreSQL database schema for TicketDesk Enterprise, including tables for:

- Audit logging (100% traceability for LGPD compliance)

## Scope

### In Scope
- users table (id, email, password_hash, role, created_at, updated_at)
- roles table (id, name, permissions JSON array)
- sessions table (id, account_id FK, status, created_at, deleted_at)
- audit_logs table (id, user_id FK, action, resource, resource_id, changes JSONB, timestamp)
- Alembic migration files for version control
- SQL constraints (unique, not null, foreign key)
- Indexes for O(1) lookups by email, account_id, status

### Out of Scope
- Application-level logic
- Data fixtures or seed scripts
- Migration rollback procedures (documented separately)
- Performance tuning (will be done post-implementation)

### Automated Tests
File: `tests/unit/test_db_schema.py`

```python
def test_users_table_exists():
    """Verify users table created"""
    assert table_exists("users")

def test_users_columns():
    """Verify users columns"""
    cols = get_columns("users")
    assert "id" in cols
    assert "email" in cols
    assert "password_hash" in cols
    assert "role" in cols

def test_sessions_soft_delete():
    """Verify soft-delete pattern (deleted_at)"""
    cols = get_columns("sessions")
    assert "deleted_at" in cols

def test_indexes_exist():
    """Verify indexes on frequently filtered columns"""
    indexes = get_indexes()
    assert "email_idx" in indexes
    assert "account_id_idx" in indexes
    assert "status_idx" in indexes

def test_foreign_keys():
    """Verify FK constraints"""
    assert fk_exists("sessions", "account_id", "users", "id")
    assert fk_exists("audit_logs", "user_id", "users", "id")
```
